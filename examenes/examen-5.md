1. Una empresa de análisis de datos está construyendo una aplicación de alto rendimiento que requiere escrituras concurrentes a un volumen de almacenamiento en bloque compartido desde múltiples instancias de Amazon EC2. Las instancias EC2 están basadas en Nitro y residen dentro de la misma Zona de Disponibilidad. La empresa necesita una solución de almacenamiento que admita conexiones simultáneas para facilitar la resistencia de datos y alta disponibilidad. ¿Qué solución cumplirá estos requisitos?
	 Al solicitar escrituras concurrentes simplemente EBS SSD IOPS Provisionadas con multi-attach es la mejor opcion ya que con multi attach podemos adjuntar el volumen a varias instancias y este tipo de volumen especifico esta creado para soportar cargas de trabajo intensivas en I/O

2. Una empresa tiene una aplicación web alojada en la nube de AWS, donde los registros de la aplicación se envían a Amazon CloudWatch. Últimamente, la aplicación ha experimentado algunos errores que pueden resolverse simplemente reiniciando la instancia. ¿Qué harías para reiniciar automáticamente las instancias EC2 cada vez que ocurra el mismo error de aplicación?
	 Primero, revisar los registros de CloudWatch en busca de palabras clave relacionadas con el error de la aplicación para crear una métrica personalizada. Luego, crear una alarma de CloudWatch para esa métrica personalizada que invoque una acción para reiniciar la instancia EC2

3. Una empresa necesita almacenar datos de una aplicación. Los datos en la aplicación cambian frecuentemente. Todos los niveles de datos almacenados deben ser auditados bajo una nueva regulación a la que la empresa se adhiere. La capacidad de almacenamiento de la aplicación se está agotando en la infraestructura on-premises de la empresa. Para cumplir con la nueva regulación, un arquitecto de soluciones debe descargar algunos datos de forma segura a AWS para aliviar los problemas de capacidad on-premises. ¿Qué solución cumplirá estos requisitos?
	 Al solicitarse almacenamiento hibrido AWS Storage Gateway es la mejor opcion, ya que permite acceso desde on-premise a los datos guardados en la nube y luego puede utilizarse cloudtrail para el trackeo de los eventos de gestion.

4. Una empresa realiza pruebas de rendimiento en una instancia grande de MySQL RDS dos veces por semana. Utilizan Performance Insights para analizar y optimizar consultas costosas en términos de rendimiento. La empresa necesita reducir sus costos operativos en la ejecución de las pruebas sin comprometer la integridad de los resultados. ¿Cuál de las siguientes opciones es la solución más rentable?
	 Aqui lo mas seguro es realizar una snapshot de la DB y terminarla, para que cuando sea necesario esta se active y se puedan realizar dichas pruebas de rendimiento sin afectar a la fuente de datos original y optimizando los costos.

5. Un banco de inversión multinacional tiene una aplicación web que requiere un mínimo de 6 instancias EC2 en ejecución para atender a sus usuarios en todo el mundo. Se te ha instruido para garantizar la tolerancia a fallos de este sistema. ¿Cuál de las siguientes opciones es la mejor?
	 Al requerirse un minimo de 6 instancias activas para atender a todos los usuarios es ideal tener 9 instancias dividas en 3 por AZ para soportar la carga esperada y la alta disponibilidad solicitada.

6. Una universidad ha implementado un sistema de inscripción en línea que se ejecuta en Amazon RDS. El arquitecto de soluciones debe monitorear métricas mejoradas en Amazon CloudWatch para garantizar la disponibilidad del sistema de inscripción. ¿Cuáles son las métricas mejoradas que Amazon CloudWatch recopila de instancias de Amazon RDS que proporcionan información más precisa? (Selecciona DOS)
	 aca tenemos dos metricas claves, la primera siendo Procesos secundarios de RDS (nos permite evaluar a nivel de hilos dentro de los procesos y su utilizacion de la CPU, permitiendo ver que proceso consume mas, estos procesos son aquellos soportados por la DB en uso) y OS processes (nos permite ver a nivel kernel y del sistema que procesos se estan ejecutando, tienen impacto minimo en el rendimiento pero permiten diagnosticar)

7. Una empresa tiene un Application Load Balancer (ALB) que acepta tráfico HTTP y HTTPS en los puertos 80 y 443, respectivamente. Recientemente, la empresa ha asociado un nuevo dominio a su sitio web y quiere asegurarse de que todo el tráfico HTTP dirigido a este nuevo dominio se redirija automáticamente a HTTPS para mejorar la seguridad. ¿Qué configuración de ALB debe realizarse para cumplir con este requisito?
	 Aqui como solamente podemos configurar un listener al puerto 80 y ya existia uno antes debemos ajustar/configurar el mismo para que redirecione al puerto 80

9. Una empresa de medios necesita configurar un bucket de Amazon S3 para servir activos estáticos a una aplicación web pública. ¿Qué métodos garantizan que todos los objetos cargados en el bucket de S3 puedan ser leídos públicamente en Internet? (Selecciona DOS)
	 Primero se debe de configurar la politica del bucket S3 para hacer que los objetos sean legibles publicamente y/o en la consola de S3 debemos activar la opcion que durante la carga del objeto establece el permiso de acceso publico al mismo.

12. Una startup está planificando configurar y gobernar un entorno de múltiples cuentas en AWS que sea seguro y compatible, en preparación para sus próximos proyectos. El gerente de TI requiere que la solución tenga un panel de control para la detección continua de recursos no conformes con las políticas y recursos fuera de cumplimiento en toda la empresa, además de cumplir con las mejores prácticas de estrategia de múltiples cuentas en AWS. ¿Cuál de las siguientes opciones proporciona la forma más sencilla de cumplir con esta tarea?
	 Control tower es ideal, nos permite gestionar multiples cuentas y configurar/gobernar los entornos que se les asignan de manera sencilla, ademas proporciona un panel centralizado para visibilizar todas las cuentas en uso.

13. Una empresa opera múltiples cuentas de AWS bajo AWS Organizations. Para gestionar mejor los costos, la empresa quiere asignar diferentes presupuestos para cada una de estas cuentas. La empresa también quiere prevenir el aprovisionamiento adicional de recursos en una cuenta de AWS si alcanza su presupuesto asignado antes del final del período presupuestario. ¿Qué combinación de soluciones cumplirá estos requisitos? (Selecciona TRES.)
	 Aqui hay que realizar varios pasos, el primero es configurar un rol de IAM con los permisos necesarios que permitan a AWS Budgets ejecutar acciones de presupuesto, luego deberiamos usar AWS Budgets para establecer diferentes presupuestos para cada cuenta de AWS usando la consola de Billing and cost management y por ultim debemos configurar las alertas de AWS budgets para notificar a la empresa cuando se este a punto de alcanzar el umbral y luego usar la accion de presupuesto del rol IAM para evitar el aprovisionamiento adicional de recursos.

1. Una multinacional está almacenando archivos confidenciales en un bucket de S3. El equipo de seguridad realizó recientemente una auditoría y el informe mostró que varios archivos se habían subido sin cifrado del lado del servidor (SSE) con AES-256. Para una protección adicional, la clave de cifrado debe rotarse automáticamente cada año. El arquitecto de soluciones debe garantizar que en el futuro no se suban archivos sin cifrar en el bucket de S3. ¿Cuál de las siguientes opciones cumplirá estos requisitos con el menor esfuerzo operativo?
	 Lo mejor en este caso es crear una bucket policy que deniegue los objetos cargados al bucket sin el header S3:x-amz-server-side-encryption: "AES256" y habilitar el cifrado del lado del servidor con SSE-S3 confiando en la rotacion de claves del bucket (365 dias), es idoneo pensar en la validacion especificamente a nivel bucket ya que otras opciones como hacerlo a nivel servicio afectan a toda la cuenta de AWS ademas de que las claves de SSE-S3 no son modificables manualmente.

2. Un grupo de Auto Scaling (ASG) de instancias Linux EC2 tiene un sistema de archivos Amazon FSx para OpenZFS con monitoreo básico habilitado en CloudWatch. El arquitecto de soluciones notó que la aplicación heredada alojada en el ASG tarda mucho en cargarse. Después de revisar las instancias, el arquitecto se dio cuenta de que el ASG no está lanzando más instancias como debería, a pesar de que los servidores ya tienen un alto uso de memoria. ¿Cuál de las siguientes opciones debería implementar el arquitecto para resolver este problema?
	 En estos casos de metricas mejoradas y especificamente a nivel de instancias instalar el agente unificado de cloudwatch es idoneo, ya que nos permitira verificar el uso de memoria de la EC2 pudiendo crear una metrica de escalado valida para el ASG.

3. Una empresa opera múltiples cuentas de AWS bajo AWS Organizations. Para gestionar mejor los costos, la empresa quiere asignar diferentes presupuestos para cada una de estas cuentas. La empresa también quiere prevenir el aprovisionamiento adicional de recursos en una cuenta de AWS si alcanza su presupuesto asignado antes del final del período presupuestario. ¿Qué combinación de soluciones cumplirá estos requisitos? (Selecciona TRES.)
	 Primero debemos configurar un rol de IAM que permita a AWS Budgets ejecutar acciones, a raiz de esto creamos mediante la consola de AWS Billing and Cost Management umbrales precisos de costos por servicio para estrablecer guardtrails y margenes claros, posteriormente se configurara una alerta de AWS Budgets para que si un umbral se ve en su limite notifique a la empresa y ejecute una accion gracias a su rol de IAM para evitar que se aprovisione el recurso que superaria dicho limite.
