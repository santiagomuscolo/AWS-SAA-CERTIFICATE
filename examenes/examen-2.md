1. Una empresa planea alojar una aplicación web en un grupo de Auto Scaling de instancias Amazon EC2. La aplicación será utilizada globalmente por usuarios para cargar y almacenar varios tipos de archivos. Basado en las tendencias de uso del usuario, los archivos que tengan más de 2 años deben almacenarse en una clase de almacenamiento diferente. El arquitecto de soluciones de la empresa necesita crear una solución escalable y rentable para almacenar los archivos antiguos, al mismo tiempo que proporciona durabilidad y alta disponibilidad. ¿Cuál de los siguientes enfoques se puede utilizar para cumplir con este requisito? (Selecciona DOS)
	 Cuando nos referimos a almacenamiento a largo plazo lo mejor es S3, ya que escala automaticamente, es altamente disponible y economico frente a la capacidad de almacenamiento que el mismo presenta, en este caso se ofrecieron dos opciones claves S3 Glacier y S3 standard Infrequent Access.

2. Una empresa de análisis de datos está alojando un data lake que consiste en datos en Amazon S3 y Amazon RDS para PostgreSQL. La empresa necesita una solución de informes que proporcione visualización de datos para el conjunto de datos más reciente e incluya todas las fuentes de datos dentro del data lake. Solo el equipo de gestión de la empresa debe tener acceso completo a todas las visualizaciones. El resto de la empresa debe tener solo acceso limitado. ¿Qué solución cumplirá estos requisitos?
	 Lo mejor para visualizacion de datos de forma centralizada sin lugar a dudas es Quicksight pero se presenta la problematica del acceso a la organizacion, el mismo debe hacerse compartiendo el acceso al panel a usuarios y grupos, IAM y sus roles en este caso no servirian ya que no se pueden asociar roles al panel.

3. Una plataforma de educación en línea está alojada en un grupo de Auto Scaling de instancias EC2. Debido a la variabilidad en la demanda, a veces hay más instancias de las necesarias, lo que genera costos adicionales. El equipo de operaciones ha solicitado a un arquitecto de soluciones que optimice la infraestructura para garantizar una gestión eficiente de los recursos sin afectar el rendimiento de la aplicación. ¿Qué política de escalado dinámico se debe utilizar para cumplir con este requisito?
	 Es importantisimo el punto de que se presenta una "variabilidad en la demanda", un escalado simple reacciona a alarmas de cloudwatch pero frente a periodos de enfriamiento podria producir demoras en la respuesta bajo demanda, por lo que un "target tracking scaling" es ideal, ya que responde en tiempo real a la metrica trackeada.

4. Una empresa de análisis de datos planea migrar su plataforma de procesamiento de grandes volúmenes de información desde servidores Microsoft Windows locales a Amazon Web Services (AWS). La solución debe garantizar alta disponibilidad en múltiples Availability Zones y ofrecer acceso de baja latencia al almacenamiento en bloque. ¿Cuál de las siguientes soluciones cumplirá con estos requisitos?
	 Uno pensaria que windows FSx for windows file server es una solucion idonea pero este no ofrece replicacion multi-AZ activo-activo incumpliendo el requisito de alta disponibilidad, para ello FSx netapp ONTAP es idoneo ya que ofrece almacenamiento en bloque de baja latencia y alta disponibilidad, ademas de que su uso es clave para entornos windows con grandes cargas de trabajo.

5. Una aplicación Docker, que se ejecuta en un clúster de ECS detrás de un balanceador de carga, utiliza intensamente DynamoDB. Se te ha pedido que mejores el rendimiento de la base de datos distribuyendo uniformemente la carga de trabajo y utilizando eficientemente el rendimiento aprovisionado. ¿Cuál de las siguientes opciones considerarías implementar en tu tabla de DynamoDB?
	 Es sumamente importante entender que las partition keys permiten una distribucion equitativa de la carga para que la misma no se centre en unas pocas, al aumentarlo con atributos de alta cardinalidad, distribuiremos dicha carga ofreciendo una cantidad significativa de identificadores unicos evitando "hot partitions" que pueden limitar el throughput y causar throttling.

6. Una empresa requiere que todos los datos almacenados en la nube sean cifrados en reposo. Para integrarse fácilmente con otros servicios de AWS, deben tener control total sobre el cifrado de las claves creadas y la capacidad de eliminar inmediatamente el material de clave de AWS KMS. La solución también debe permitir auditar el uso de la clave independientemente de AWS CloudTrail. ¿Cuál de las siguientes opciones cumplirá con este requisito?
	 Lo correcto seria crear una clave KMS en un almacen de claves personalizado y almacenar el material de clave no extraible en CloudHSM ya que nos ofrece la posibilidad de tener un control total y directo de la clave en un HSM (Hardware security module) dedicado.
	 Si la clave fuese administrada por el usuario no podriamos auditarla independientemente de cloudtrail, no podriamos eliminar el material inmediatamente y tampoco podriamos tener un control fisico del material de la clave.

7. Una compañía está diseñando una aplicación bancaria que utiliza Amazon ElastiCache for Redis como su componente de administración de sesiones distribuidas. Para asegurar los datos de sesión y garantizar que los ingenieros en la nube se autentiquen antes de ejecutar comandos Redis, específicamente comandos MULTI EXEC, el sistema debe reforzar una autenticación robusta requiriendo a los usuarios ingresar una contraseña. Además, el acceso debe gestionarse con credenciales de larga duración mientras se mantienen prácticas de seguridad sólidas. Como Solutions Architect, ¿cuál de las siguientes opciones debes implementar para cumplir con el requisito anterior?
	 Para este caso de uso se deberia de utilizar REDIS AUTH + los parámetros --transit-encryption-enabled y --auth-token habilitados, ya que de esta manera protegemos la ejecucion de comandos entre nodos del cluster cifrandolos en vuelo y solicitamos una contrasena antes de poder ejecutarlos (REDIS AUTH con parametro --auth-token).
	 En este caso no nos serviria IAM ya que los tokens expiran cada 12 horas por lo que no cumple con el requisito de larga duracion y ademas es incompatible con comandos de REDIS MULTI EXEC

8. Una empresa de e-Learning aloja su aplicación en .NET en un servidor Windows en su centro de datos on-premises. La aplicación utiliza Oracle Database Standard Edition como base de datos. La compañía quiere migrar esta carga de trabajo a AWS para aprovechar la alta disponibilidad de la nube, minimizando los cambios de desarrollo y simplificando la gestión del entorno. ¿Cuáles de las siguientes opciones deberían implementarse para cumplir con los requisitos de la empresa? (Selecciona DOS)
	 Para esta migracion es ideal usar Database Migration Service para la base oracle y re-hostear la aplicacion .NET en un entonro Multi-AZ de Beanstalk ya que al ser serverless no es necesario aprovisionar por lo que escala automaticamente, es altamente disponible y no requiere cambios en el codigo.

9. Una plataforma de pagos en línea necesita desplegar al menos 2 instancias EC2 para manejar las transacciones normales y escalar automáticamente hasta 6 instancias EC2 para procesar la carga máxima. La arquitectura debe ser altamente disponible y tolerante a fallos, ya que la aplicación maneja pagos en tiempo real y no puede permitirse interrupciones. Como Solutions Architect, ¿qué deberías hacer para cumplir con este requisito?
	 Para este caso es ideal establecer el ASG en un minimo de 4 y maximo de 6, de tal manera que podemos soportar la carga minima (2 instancias) y ofrecer alta disponibilidad si surgen problemas en el AZ

10. Una agencia gubernamental planea almacenar documentos confidenciales sobre salud en AWS. Debido a la naturaleza sensible de la información, el arquitecto de soluciones debe restringir el acceso a los datos para que solo las solicitudes provenientes de una VPC específica puedan acceder al bucket de almacenamiento. Además, la solución debe evitar que los archivos sean eliminados o sobrescritos para cumplir con el requisito normativo de utilizar un modelo de almacenamiento Write-Once-Read-Many (WORM). ¿Cuál de las siguientes combinaciones de opciones debería implementar el arquitecto de soluciones? (Selecciona DOS)
	 Aqui sin lugar a dudas entra S3 con su object lock y legal hold para permitir el almacenamiento WORM, y para cumplir con el acceso limitado puede utilizarse su funcionalidad Access Point que permite conectarse desde multiples redes privadas al mismo.
	 WAF puede proteger VPCs de ataques y amenazas externas pero no puede proteger exclusivamente a S3.


11. Una aplicación consta de múltiples instancias EC2 en subredes privadas distribuidas en diferentes zonas de disponibilidad. La aplicación utiliza un solo NAT Gateway para descargar parches de software de Internet hacia las instancias. Se requiere proteger la aplicación de un solo punto de falla si el NAT Gateway falla o si la zona de disponibilidad en la que está implementado queda inactiva. ¿Cómo debería el Solutions Architect rediseñar la arquitectura para que sea más altamente disponible y rentable?
	 Aqui el natgateway es el punto de salida a internet y necesitaremos configurar las tablas de rutas las subredes privadas para poder acceder a las mismas

12. Un arquitecto de soluciones a cargo de una aplicación crítica debe asegurar que las instancias de Amazon EC2 puedan ser lanzadas en otra Región de AWS en caso de un desastre. ¿Qué pasos debe tomar el arquitecto de soluciones? (Selecciona dos).
	 Aqui lo mejor es que para alta disponibilidad es crear AMIs de las instancias actuales, copiarlas en otra region y lanzarlas a partir de las mismas.

13. Una empresa de telecomunicaciones gestiona una API que permite a los usuarios modificar planes móviles y servicios contratados. Durante eventos como cierres de facturación o campañas promocionales, el tráfico hacia esta API se incrementa drásticamente. La empresa necesita asegurar tiempos de respuesta consistentes con baja latencia, incluso durante picos de tráfico, y al mismo tiempo minimizar el esfuerzo de administración de infraestructura. ¿Cuál es la solución más eficiente para satisfacer estos requisitos?
	 Para este tipo de problemas donde yace una solicitud de baja latencia y buena disponibilidad frente a picos de trafico API Gateway y Lambda sigue siendo el combo ganador auqnue en este caso podemos aprovisionar la Lambda con la concurrencia necesaria para tolerar la carga.


14. Una empresa tiene varias cuentas de AWS que son usadas por desarrolladores para entornos de desarrollo, pruebas y preproducción. La empresa ha recibido facturas elevadas por instancias de Amazon EC2 que están subutilizadas. Un arquitecto de soluciones ha sido encargado de restringir la capacidad de lanzar instancias grandes de EC2 en todas las cuentas. ¿Cómo puede el arquitecto de soluciones cumplir este requisito con el menor esfuerzo operacional?
	 Aqui lo mejor para reducir el esfuerzo operacional es crear una OU y asignar una poltiica de control de servicios SCP para negar el lanzamiento de instancias grandes.
	 No podriamos asignar una politica basada en recurso a EC2 en AWS esto solo puede hacerse en S3 y Lambda.

15. Una empresa alojó un sitio web de comercio electrónico en un grupo de Auto Scaling de instancias EC2 detrás de un Application Load Balancer. El Solutions Architect notó que el sitio web está recibiendo una gran cantidad de solicitudes externas ilegítimas desde múltiples sistemas con direcciones IP que cambian constantemente. Para resolver los problemas de rendimiento, el Solutions Architect debe implementar una solución que bloquee las solicitudes ilegítimas con un impacto mínimo en el tráfico legítimo. ¿Cuál de las siguientes opciones cumple con este requisito?
	 Aqui lo mejor seria asociar un WAF con una regla basada en tasa a la VPC y asociar un ACL al ALB de tal manera que tengamos una doble validacion del trafico entrante.

1. Una empresa global de manufactura con oficinas en todo el mundo tiene varias cuentas de AWS. Para mejorar la eficiencia y reducir costos, el Director de Información (CIO) desea implementar una solución que administre centralmente sus recursos de AWS. Esto les permitirá aprovisionar recursos de AWS de manera centralizada y compartir recursos, como AWS Transit Gateways, configuraciones de AWS License Manager o reglas de Amazon Route 53 Resolver, en sus diferentes cuentas. Como arquitecto de soluciones, ¿qué combinación de opciones deberías implementar en este escenario? (Selecciona DOS)
	 La centralizacion del manejo de recursos y la capacidad de compartirlos se realiza mediante AWS RAM (Resource Access Manager) y AWS Organizations para manejar de forma generalizada grupos de usuarios.

2. Una empresa de biotecnología ha migrado recientemente su infraestructura de aplicaciones a un clúster de Amazon Elastic Kubernetes Service (Amazon EKS). Como parte de su estrategia de seguridad, necesita garantizar que todos los secretos de configuración y credenciales, como contraseñas de bases de datos y claves API, se almacenen de forma segura y cifrada dentro del almacén de claves de valor etcd de Amazon EKS. ¿Cuál es la mejor solución para cumplir con estos requisitos de seguridad?
	 etcd (es como una base de datos distribuida que usa kubernetes para almacenar el estado del cluster) almacena datos sensibles en el cluster de EKS, por lo que la forma mas sencilla de manejar los secretos es cifrandolos en etcd dentro del cluster y utilizando KMS para la generacion y control de la clave.
